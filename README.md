# 坦克大战游戏

一个使用纯HTML、CSS和JavaScript开发的坦克大战游戏。

## 游戏特点

- 🎮 纯前端实现，无需后端服务器
- 🎯 简单直观的操作方式
- 💥 炫酷的爆炸效果
- 📊 实时分数统计

## 操作说明

- **W/A/S/D**: 控制坦克移动
- **空格键**: 发射子弹
- **ESC**: 暂停/继续游戏

## 游戏玩法

- 消灭从顶部出现的敌方坦克
- 避免敌人的子弹攻击
- 不要让敌人坦克到达底部
- 每击毁一个敌人坦克获得100分
- 生命值为0时游戏结束

## 在线试玩

直接打开 `index.html` 文件即可开始游戏！

## 技术栈

- HTML5 Canvas
- CSS3
- Vanilla JavaScript
